# Места, где конструкция из аудита есть, но не стреляет. Каждая строка —
# разбор, а не отписка: почему именно здесь код возврата никуда не попадает.
#
# Формат:  файл :: правило :: код :: обоснование
#
# Если код изменится, строка перестанет к чему-либо относиться, и аудит
# сообщит об этом отдельно — чтобы список не гнил.
bin/awg-datapath.sh :: colon-plus-flag :: log "$IFACE настроен (MTU ${MTU:-1380}${SUBNET:+, подсеть $SUBNET}${NAT:+, NAT=$NAT})" :: строка лога: NAT это 0 или 1, и «NAT=0» в сообщении читается верно; на поведение не влияет
bin/awg-datapath.sh :: pipe-fallible :: awg-quick strip "$IFACE" | grep -vE '^__AWG3?_OBFUSCATION__$' > "$stripped" :: отказ awg-quick strip означает отсутствующий конфиг интерфейса — продолжать в этом случае нечего, смерть здесь и есть верный исход
bin/awg-doctor.sh :: pipe-fallible :: conf="$(ls -1 "$DEST/clients/$svc"/*"$tmp"*-am.conf 2>/dev/null | head -1)" :: файл идёт без set -e: отказ конвейера оставляет пустое значение, и диагностика продолжается — это её штатное поведение
